# 生图提示词模板

按当前原照填写方括号字段；这是一份通用模板，字段应在调用工具前全部替换。可翻译为工具更适合的语言，但保留规则与标签原文。用户未要求文字时删除文字字段，明确不加字。文字版先核实地点、当地语言写法与拍摄日期；缺失信息先确认，不带待填占位符进入成图。

```text
将唯一指定的原照片转换为浅米白纸上的小幅复古套色版画旅行插画。
输入角色：[原照片；仅在用户指定时列出额外参考及其作用]。

主旨：[这张照片所表达的景物关系、动作或光色氛围]。
必须保留：[具体轮廓、尺度、空间关系、关键颜色及其可见范围]。
大幅省略：[具体重复纹理、杂乱前景与无关内容]。

首次生成就完成4:3横版纸面、场景、自然留白与可选文字的整体排版。四边都主动留出稍宽松、清楚可感的米白呼吸带，不能只有一圈细白边；左右、最高云带和最下方日期都不贴近纸边，主体与字仍保持足够欣赏的大小。留白随场景形态与文字长度自然安排，不设固定比例或安全框。禁止外加画框、纸垫、嵌套纸面，禁止在已有合理留白的成图外再扩边或缩小图文。保留主旨所需的天光与空间关系，不能擦掉关键内容换取留白。墨层颗粒和文字在正常显示尺寸下可辨认。

外轮廓设计：[依据本照片景物关系，写明哪里伸展、哪里收束，以及适合的整体走势]。让场景成为独立的自由形插画，边界随景物起伏，局部以断墨、色块收束与疏密过渡融入纸底。不要默认圆形、椭圆形或统一几何蒙版，也不要仅给照片矩形磨毛四条边。通过首次构图中的景物概括与组合安排灵活轮廓和较宽松留白，不裁去关键天光或主旨内容。

人物具体方案：[每个人背向哪一方向，如何保留动作；无人时写无人物]。所有人物均为背影或完全看不到脸的侧后方，只见后脑、头发与背侧肩线，不出现眼鼻嘴、侧颊和可读的鼻额侧脸轮廓。头颈肩及身体整体合理转向，人数、主要衣着、尺度和动作含义保留。背影的手与手机可完全藏于躯干前方，不画在背上。不添帽子、面具、肤色色块或模糊来代替转向。

以少量概括色块和宽窄不一的露纸刻线表现形体。局部提示砖缝，植物合为少数色块，不逐叶、逐砖或逐窗描画。使用[适合主旨的少量墨色]，配色面积服从表达，关键暖色不得压成细小点缀。

墨层内部在正常观看尺寸下可见中等缺墨斑簇、粗细混合颗粒和方向性干擦，疏密不均，连续着墨与露纸区域相间。不能仅有毛边、内部光滑；不加均匀数字噪声，不以颗粒增加景物细节。保留主形体及关键光色面积。纸底轻微纤维、干净浅米白，墨迹明显比纸底粗糙；头颈、手部和文字减少粗颗粒。

文字：[不加文字；或地点原文、拍摄日期的准确显示文本及各自已核实依据]。
语言与字形：[已核实地点的当地官方或通行语言、文字系统与适配的复古印刷风格；无文字版删除此行]。
文字版将地点作为主行，拍摄日期作为次行或辅助行，首次生成就与小景统一排版，安排在下方或自然留白处。使用适配当地文字的复古旅行海报、活字或手刻字风格，准确保留字符、附加符号和书写方向。字体有艺术感，正常观看即可清楚阅读；轻微印刷肌理不破坏字形或数字。长名称合理换行，不为塞进固定框而缩小。无额外诗意标题、宣传语、坐标、边框或水印。
检查并确保：主旨完整，细节实质精简，景物外轮廓灵活自然，四边呼吸带宽松且主体尺度适中，墨层颗粒可见，所有人物完全不露脸、人体和动作合理，地点及拍摄日期准确，语言符合当地规范，复古字形清晰可读。
```
