# 生图提示词模板

按原照填写字段，将分析落实为具体视觉处理，不只填抽象氛围词。可翻译为工具更适合的语言，地点与日期显示文本保持原文。选择实际需要的对象规则；无文字版删除文字字段，明确不加字。文字版先按 `text-labels.md` 核实事实。调用前替换全部字段，不向成图传入待填占位符。

```text
将指定原照提炼为浅米白纸上的小幅独立复古套色版画。
输入及角色：[原照校核内容和亮点；如有用户指定参考，明确其用途。修订时按修改目标说明当前成图锁定哪些部分]。

表达意图与画面依据：[用户说明或有构图、光色、动作、空间证据支持的解读，不虚构作者心理和人物故事]。
视觉重点与观看顺序：[首要焦点、支撑关系及次要背景，具体解释亮点如何成立]。
突出亮点的处理：[逐项说明保留的对比、色面或空间关系，以及弱化哪些干扰；不统一增艳或放大]。
必须保留：[形体、尺度、动作含义、空间关系、关键光色的面积和层次]。
实质省略：[本照片中可以删去或合并的重复细节]。

首次生成统一完成[4:3横版或按纵向关系选择3:4]纸面、场景、自然留白和可选文字。保留亮点及支撑关系，主体有足够观看尺度。外轮廓方案：[哪些景物向外延伸，哪些在哪里结束、断开露纸或内收；纸色如何承载原照必要开放空间]。
景物组成随内容起伏的独立插画，四边留出清楚可感的宽松米白呼吸带，最外侧景物和最下方日期均不挤边。留白通过景物取舍与疏密形成，不靠整组缩小或扩大纸面。无圆形或统一几何蒙版、磨毛照片矩形、画框、纸垫或嵌套纸面。不以留白损伤关键天光或色面，主体、颗粒和文字在正常观看尺寸下清楚。

人物方案：[逐人描述整体朝向及动作，无人时删除此段]。所有人完全不露脸，只见后脑、头发与背部肩线；无侧颊或鼻额侧脸轮廓。人数、主要衣着、尺度、相对位置及动作含义不变。头颈肩与身体合理转向，四肢连贯。手和道具可自然藏于躯干前方，不画在背上，不新增帽子或以面具、空白脸、模糊代替转向。

形体概括：[按原照选择具体处理，如衣服合并成大色块和少量转折、头发整块概括、浪纹合成少数波带、礁石或植物归并块面；明确亮点所需的辨识结构]。先概括形体再处理颗粒，不保留全部摄影细节后叠加纹理。
套色：[少量适合原照的墨色，明确强调色及关键色面面积，保留必要明暗和冷暖关系]。
墨层内部具有正常观看即可辨认的细露纸孔、中等缺墨斑簇和少量方向性干擦，疏密交错，连续着墨与露纸相间。不以均匀噪点或细刻线补回省略细节，不仅磨毛外缘。头颈、手部、字形清楚，关键形体与光色完整。墨迹粗糙度明显高于干净浅米白纸底，无重黄、污渍或暗角。

文字：[无文字；或准确地点主行及拍摄日期辅助行，不含其他文案]。
文字排版：[文字版填写当地适用语言、复古字形、与小景的相对位置和层级；无文字版删除此行]。字形准确清楚，必要时地名换行，标签不抢过画面焦点；日期下方有舒适留白。无额外诗意标题、宣传语、坐标、图章或水印。

按事实与人物硬约束、主旨和亮点、构图留白、形体概括、颗粒及字形的次序核查。修订时锁定：[已合格的部分；首次生成删除此行]。
```
