# 生图提示词模板

按当前原照填写方括号字段；这是一份通用模板，字段应在调用工具前全部替换。可翻译为工具更适合的语言，但保留规则与标签原文。用户未要求文字时删除标签字段，明确不加字。

```text
将唯一指定的原照片转换为浅米白纸上的小幅复古套色版画旅行插画。
输入角色：[原照片；仅在用户指定时列出额外参考及其作用]。

主旨：[这张照片所表达的景物关系、动作或光色氛围]。
必须保留：[具体轮廓、尺度、空间关系、关键颜色及其可见范围]。
大幅省略：[具体重复纹理、杂乱前景与无关内容]。

默认4:3横版纸面，图文整体位于正中央。全部笔触与标签的联合外沿放入纸面x22%—78%、y25%—75%以内，四边保持大面积干净米白留白。先组合图文再等比缩放，不拉伸，不填满占位框。云带、枝叶、倒影、人物和文字均计入边界。主旨所需的内部天光与关系完整保留，通过缩小整组内容获得外部留白。

人物具体方案：[每个人背向哪一方向，如何保留动作；无人时写无人物]。所有人物均为背影或完全看不到脸的侧后方，只见后脑、头发与背侧肩线，不出现眼鼻嘴、侧颊和可读的鼻额侧脸轮廓。头颈肩及身体整体合理转向，人数、主要衣着、尺度和动作含义保留。背影的手与手机可完全藏于躯干前方，不画在背上。不添帽子、面具、肤色色块或模糊来代替转向。

以少量概括色块和宽窄不一的露纸刻线表现形体。局部提示砖缝，植物合为少数色块，不逐叶、逐砖或逐窗描画。使用[适合主旨的少量墨色]，配色面积服从表达，关键暖色不得压成细小点缀。

墨层内部在正常观看尺寸下可见中等缺墨斑簇、粗细混合颗粒和方向性干擦，疏密不均，连续着墨与露纸区域相间。不能仅有毛边、内部光滑；不加均匀数字噪声，不以颗粒增加景物细节。保留主形体及关键光色面积。纸底轻微纤维、干净浅米白，墨迹明显比纸底粗糙；头颈、手部和文字减少粗颗粒。

文字：[不加文字；或精确标签原文及已核实依据]。要求标签时只在小景下方用小号朴素中文印刷字排出地点名，并计入图文占位。无额外标题、日期、译名、坐标、边框、装饰横线或水印。

检查并确保：主旨完整，细节实质精简，四边留白合格，墨层颗粒可见，所有人物完全不露脸、人体和动作合理，文字准确可读。
```
