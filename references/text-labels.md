# 文字版：地点、拍摄日期与复古字形

用户要求文字版时，默认同时加入**地点与拍摄日期**；明确要求无日期或自定文案时遵循用户要求。只写这些事实信息，不另起诗意标题或宣传语；坐标和额外译文仅按要求添加。

### 地点与语言

1. 读取原图 GPS、位置描述等元数据；用户明确提供的地点也可作为依据。
2. 结合地图、可靠地名资料和画面核对。注意坐标系差异；GPS 是拍摄位置，远眺建筑、航拍山峰或邻近敌楼不能直接按最近地图标记命名。
3. 优先核实具体建筑、景点或区域；无法确认时使用已核实的上一级地名。用户只确认到国家或城市时，直接采用该层级，不为更细地名重复追问。完全无法核实则与其他事实缺口合并简短询问，先完成画面分析与构图方案，不猜名填空，也不先生成缺字占位稿。
4. 按已确认地点，优先采用该国家或地区的官方语言及其本地文字书写地名；优先查找当地政府、景点或权威地名来源中的正式名称，不默认统一转成中文、英文或拉丁转写。
5. 有多种官方语言时，优先选择当地实际使用、与地名对应的官方语言；仍有多个同等合理选择时简短询问。没有统一官方语言时，采用当地通行且有可靠来源的地名写法。不得仅凭国家标签臆定一种语言；用户指定语言优先。
6. 保留正确的字符、附加符号、字形连接和书写方向。无法可靠核实拼写或工具难以正确排字时，说明具体缺口并确认替代方案，不生成伪文字。

### 拍摄日期

- 优先读取原文件 EXIF 的 `DateTimeOriginal` 及对应时区信息；可使用用户明确确认的拍摄日期。其他元数据仅在能确定其含义确为拍摄时间时采用。
- 不用文件修改时间、下载时间、上传时间、来源网页发布日期或图片生成日期冒充拍摄日期；不从无可靠解释的文件名猜日期。
- 按拍摄地当地日期排版；已有偏移信息时正确换算。原始相机时间无时区时，不擅自作跨时区换算；存在跨日歧义或来源冲突时询问。
- 日期只明确到年月时，保留该精度，不补造具体日。缺失或不可靠时，与未确认地点等问题合并简短询问，先推进不依赖文字的工作；不要声称文字版已经完整完成，也不要自动填入当天日期。
- 日期采用当地易读且无歧义的形式；可用当地月份写法，或清晰的 `YYYY-MM-DD`。不默认加入时分秒。

### 复古艺术排字

- 地点作为主行，拍摄日期作为次行或较小辅助行；两者与插画在首次生图中统一设计，整体可读、有呼吸感。长地名可合理换行，不为一行排完而无限缩小。
- 选择适配当地文字系统的复古旅行海报、活字印刷或手刻字风格。拉丁文字可用有性格的衬线、窄体海报字；汉字可用宋体、木刻或老招贴字意；其他文字采用其自身的印刷传统，不套用拉丁字形特征。
- 字形有艺术感，但结构、拼写、标点和日期必须准确。墨色与画面协调，可有轻微不规则墨边或压印感；字腔、细笔画与数字保持清楚，不用粗颗粒打碎文字。
- 不添加浮夸文案、装饰性乱码或与地点无关的图章。字形调整不改变已核实的文字内容。
